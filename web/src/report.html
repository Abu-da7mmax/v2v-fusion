How It Works

The original model estimates relative 3D translation and heading from synchronized sensors. GPS provides target labels during training and validation.

RF encoder

Concatenate the four beam-power files into 256 values, log-transform and standardize the input, then pass it through a 1D CNN.

Vision encoder

Resize the RGB input to 96 × 96 and normalize it. EfficientNetB0 extracts image features for fusion.

LiDAR encoder

Filter zero-range points. Compute mean, standard deviation, minimum, maximum and the 25th and 75th percentiles for each of five channels to form 30 features.

Cross-modal attention

The three modality embeddings form a three-token sequence. Two self-attention layers let each sensor representation interact with the other two. Separate heads predict position and heading.

Evaluation

For each sample, the 3D position error is the Euclidean distance between predicted and true offsets. RMSE gives more weight to large errors. Median describes the midpoint of the errors and P90 the value below which 90% fall. Heading accuracy counts predictions within an angular tolerance.

About the Project

This graduation project estimates the pose of one vehicle relative to another using synchronized radio, vision and LiDAR measurements. The original system used TensorFlow, Angular and FastAPI.

The interface follows the report's dashboard layout and uses its original captured sample and evaluation tables. The Dataset Explorer documents all four releases. External data can be obtained through the official DeepSense portal.
